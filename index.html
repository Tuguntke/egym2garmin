How it works
  1. Screenshot the "Training details" screen in the eGym app.
  2. The app reads it on your device and builds a Garmin-ready FIT file — nothing is uploaded.
  3. Import the FIT file into Garmin Connect; it syncs to Strava automatically if linked.
